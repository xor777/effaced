# Instrument bank v1 — sources

Generated by `node tools/build-instruments.ts`. Every sampled zone below was made from recordings of two CC0 (public domain) libraries by Versilian Studios:

- `vsco2ce/…` = https://github.com/sgossner/VSCO-2-CE (branch master) — CC0 1.0
- `vcsl/…` = https://github.com/sgossner/VCSL (branch master) — CC0 1.0

File paths are relative to the repository root (drop the `vsco2ce/` / `vcsl/` prefix). The raw downloads are not kept in this project; `node tools/bank/fetch-samples.ts` re-downloads exactly the files listed at the end into `samples/` (79 files, ≈90 MB), after which the build reproduces this bank.

Notes are scientific pitch (C4 = middle C = tracker C-4).

Common processing: stereo → mono (L+R, or the louder channel when the pair is anti-correlated); onset trimmed; pitch measured and every pitched zone resampled (Kaiser-windowed sinc) to an XM-exact rate so libopenmpt/FT2 1/16-semitone finetune is exact; DC removed; level calibrated per zone to the v0 zone that played the same key (see manifest `level`, zone `lufs`/`v0Lufs`).
